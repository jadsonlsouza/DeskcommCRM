# Versões do Gianna

## [0.1.2]

- Acesso ao painel Atualização do sistema no rodapé para administradores da instalação.
- As versões publicadas ficam disponíveis para instalação pelo painel. A publicação pode ser configurada para atualizar a VPS automaticamente.
- Preservação do arquivo Compose do proxy IP durante atualizações pelo painel.

## [0.1.1]

- Agenda semanal do Amigo no Inbox, com ocupação do médico e consulta de vagas.
- Cadastro e vínculo do paciente, agendamento, confirmação, remarcação e cancelamento pela conversa.
- Resposta configurável a saudações isoladas no atendimento automático.

## [0.1.0]

- Primeira versão do Gianna para VPS, com identidade visual própria.
- Integração Amigo com agenda, sincronização e escolha de operações por agente.
- Atualizações pela interface a partir das versões publicadas no repositório do Gianna.
